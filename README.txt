VIDARBHA VADAL - Free News Portal Starter

Files:
- index.html : homepage
- style.css  : responsive design
- script.js  : mobile menu

How to use:
1. Open index.html to preview.
2. Replace sample headlines/text with your own original content.
3. Replace the placeholder blocks with your own images.
4. For free hosting, upload these files to GitHub Pages or Cloudflare Pages.
5. Before AdSense, add genuine About, Contact, Privacy Policy and Disclaimer pages and publish original content.

Important:
This is a front-end starter, not a full CMS. A database/admin panel is needed to manage news dynamically.
